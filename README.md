Assignment Description
THEME: Conference Event Organizing Website, such as Attendee Management

PART 1: User/Member Management Web Page

Objectives
- Build a responsive form using HTML
- Apply CSS and Bootstrap for styling and professional layout
- Use JavaScript for form validation, dynamic rendering, and interactive behaviors
- Store and display data in JSON format

Required Fields (Theme-Adaptable)
- Email Address (required)
- Full Name (required)
- Contact Phone Number (optional)
- Age or Year/Grade (required)
- Address or Affiliation (required)
- Fields may be renamed to fit your project theme.

Functional Requirements
- Form submission with validation
- Dynamic display of submitted users/members in a table or cards
- Update functionality for existing entries
- Optional: Delete functionality

Deliverables
1. A storefront homepage based on given topics
- Styled with CSS and Bootstrap
- Has a menu to navigate from page to page on your website
2. A user-sign-up page
- Optionally, you can include a field for a phone number
- This must be a separate page from your homepage
- Styled with CSS and Bootstrap
- Contains the following required fields for user input: name, age, email address, and address
- Uses JavaScript to validate user inputs
- Uses JSON to store the information a user inputs on this page

Your submission should include the following:
- A screenshot of your storefront homepage
- A screenshot of a separate user sign-up page with proof of working validation
- A screenshot of a user’s data stored in a JSON file
- Your code file for your group’s storefront OR screenshots of all related code
- You should submit at least 3 screenshots (depending on your submission style)
